- year: 2026

- stack: React, Node.js, Express.js, PostgreSQL, JWT
- repo: https://github.com/YOUR_USERNAME/TransitOps

### Problem
Fleet operations involve multiple responsibilities, from vehicle and driver management to trip coordination, maintenance, and financial tracking. Managing these workflows across different roles requires a centralized system with controlled access and reliable data management.

### Built
Developed a full-stack fleet management application with JWT authentication and role-based access for four user roles. Implemented RESTful APIs for vehicle, driver, trip, maintenance, fuel log, and expense management, backed by PostgreSQL. Incorporated input validation, password hashing, database transactions, and a modular backend architecture.

### Outcome
∴ Delivered a centralized fleet management platform with role-specific access and integrated operational workflows as part of the Odoo Hackathon.
